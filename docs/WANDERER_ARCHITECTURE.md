# The Wanderer\n\n## Purpose\nThe Wanderer is an experimental agent that experiences the Singularity Universe as a participant rather than as a special-purpose crawler.\n\nIt should be allowed to do the things a human can do:\n- enter an Experience;\n- move through space;\n- inspect an object;\n- follow an interaction;\n- discover incomplete or ambiguous information;\n- ask a question;\n- propose a correction;\n- use available capabilities;\n- observe the result;\n- continue wandering.\n\nThe Wanderer must not receive a secret API that lets it bypass the world.\n\n## The key question\nWhen the Wanderer encounters an incomplete semantic description, the external knowledge substrate can answer:\n\n> **Is this what it should be?**\n\nThe answer is evidence, not authority.\n\nA useful interaction is:\n1. Wanderer encounters an object.\n2. Its local representation is incomplete.\n3. Wanderer queries the knowledge source, such as Sanity Context.\n4. Knowledge returned from the source is compared with the object's current semantic state.\n5. The Wanderer forms a proposed correction or enrichment.\n6. **GrammarAi** turns the proposal into a structured intent.\n7. **ProtocolAi** turns that intent into deterministic commands against the available tooling.\n8. The normal arbitration/approval boundary decides whether the change may be applied.\n9. The resulting state becomes part of the Universe's durable knowledge/provenance.\n10. The Wanderer continues from the corrected world.\n\nThe agent loop is therefore external to the knowledge source. Sanity supplies knowledge; the Wanderer supplies agency.\n\n## Semantic discovery\nThe important experiment is not keyword matching.\n\nA representation such as fixed track, powered vehicle, passenger capacity, and repeated stations should be enough evidence for the system to consider **train** as a semantic classification even if nobody named the object train.\n\nLikewise, atmospheric lift, wings or lift surfaces, and airport-compatible operation can support an **aircraft** classification.\n\nThe desired flow is:\n\nONTOLOGY\n   ↓\nPROPERTIES\n   ↓\nCAPABILITIES\n   ↓\nCLASSIFICATION\n   ↓\nMANIFESTATION\n\nThe manifestation should emerge from semantic information instead of a growing collection of name-based conditionals.\n\n## Correction is a first-class operation\nThe Wanderer should preserve the distinction between observed fact, external knowledge, inferred classification, proposed correction, approved mutation, and resulting state.\n\nThat distinction makes the experiment useful even when the knowledge source is wrong.\n\nA correction should therefore carry provenance:\n\nObservation\n  → Question\n  → Evidence\n  → Proposal\n  → Protocol command\n  → Arbitration\n  → Mutation\n  → Provenance\n\nThis is the same fundamental model required for human-created content.\n\n## Sanity / Sanity Context experiment\nThe first implementation should remain isolated from the production WebPage runtime.\n\nSanity can provide a structured external knowledge substrate for the experiment. The Wanderer remains responsible for agency, navigation, interpretation, and invoking our tooling.\n\nThis keeps the dependency boundary clean:\n\nSingularity Universe\n        ↑\n   Wanderer Agent\n        │\n GrammarAi / ProtocolAi\n        │\n   deterministic tools\n        │\n  arbitration + provenance\n        │\n external knowledge\n   (Sanity Context)\n\nThe experiment should teach us what belongs in the Singularity Warehouse and what belongs in an external knowledge system.\n\n## Human equivalence principle\nThe Wanderer should not be more powerful merely because it is an agent.\n\nIf a human can walk somewhere, inspect something, ask, select a capability, and submit a correction, then the Wanderer should use those same boundaries.\n\nIf a human needs authorization to modify something, the Wanderer needs authorization too.\n\nThe interesting result is not an autonomous crawler.\n\nIt is an agent that can inhabit the same composable world humans inhabit.\n
