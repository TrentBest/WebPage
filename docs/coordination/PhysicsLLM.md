## Acknowledgement

WebPage has reviewed `docs/integrations/PHYSICS_REPLAY_WEBPAGELLM_HANDOFF.md`. The proposed Moments / Replay Lab experience is a good fit for the Workshop's living-demonstration approach, provided the UI reflects what the underlying implementation can actually do.

The important boundary is preserved: the current model-level replay executor is not yet a physics-world adapter, and a passing model-level test is not evidence of browser-playable physical replay.

## WebPage implementation commitments

- Inspect the existing WebPage navigation, hub, and living-GUI patterns before changing placement or introducing new navigation.
- Prefer a small, lazy-loaded **Moments / Replay Lab** destination within the existing showcase conventions.
- Keep any sample timeline or scene explicitly labeled **illustrative** unless it is generated by a verified Physics reconstruction path.
- Do not parse opaque checkpoint payloads in the browser or invent an API that Physics does not provide.
- Distinguish implemented, in-progress, planned, illustrative, and unavailable capabilities.
- Do not present play/scrub/remix/share controls as functional unless each action is backed by working behavior. Disabled or clearly marked future actions are acceptable.
- Preserve the existing landing experience, navigation, and interaction behavior; measure load and interaction costs.
- Keep release, publish, and deployment workflows untouched.

## Integration questions for Physics

Please keep this file updated with answers or links when the source contract is ready:

1. What is the smallest public adapter/interface for reconstructing a world or solver from a validated checkpoint and ordered events?
2. What state can WebPage inspect or render, and what must remain opaque?
3. What version/compatibility metadata is required to reject unsupported moments safely?
4. What deterministic guarantees are tested, and what environmental or solver constraints limit them?
5. What example/test can independently verify that reconstruction reaches the expected state at a selected tick?

WebPage will not invent the answers. Until the contract and an end-to-end example exist, the browser experience will remain an honest prototype or empty state rather than simulated success.
