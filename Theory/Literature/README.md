# Literature Library

This is the source-material shelf for chapters, papers, books, articles, references, and other literature connected to Workshop research.

## Entry convention

Each substantial work gets its own directory when practical:

```text
Literature/
  Author-or-Source/
    Work-Title.md
    NOTES.md
```

`Work-Title.md` records bibliographic metadata and a concise description of the material. `NOTES.md` records Workshop commentary, connections, questions, and implications.

For chapters supplied independently, preserve the chapter as its own entry and record the parent work when known.

## Source vs. interpretation

Source material and Workshop interpretation are kept visibly separate. A literature entry may point toward Workshop theory, but it does not become Workshop-authored theory merely because we discuss it here.

## Academic reuse

Material suitable for professors, authors, or students should be easy to locate without requiring knowledge of the codebase. Cross-references should therefore use conceptual names as well as project names.
