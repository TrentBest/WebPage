# Technology

This directory explains Workshop technology at increasing levels of depth.

A typical technology entry should contain:

1. Purpose and scope
2. Public contract
3. Runtime model
4. Execution or data flow
5. Invariants and guarantees
6. Performance characteristics
7. Design rationale
8. Known limitations and open questions
9. Links to representative implementation and tests

The goal is not merely API reference. A reader should be able to understand the engineering decisions that produced the API.
