# Academic Theory

This directory contains Workshop-authored theoretical exposition.

These documents are not API manuals. They explain general principles discovered through implementation and experimentation, and are written so that a researcher can evaluate, challenge, extend, or cite the ideas independently of a particular application.

Suggested structure:

```text
Academic/
  Theory-Name/
    README.md
    PROPOSITIONS.md
    EVIDENCE.md
    OPEN-QUESTIONS.md
```

Where a proposition is derived from an implementation, identify the implementation and distinguish measured evidence from architectural intent.

This is also the natural destination for material that eventually becomes a professor-facing chapter, paper, lecture, or book contribution.
